# Portfolio: Programmer Cat, Ruler Scrollbar, Loading Screen and Quiet Polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give duke-portfolio a smug programmer cat (hero, loading screen, riding a custom ruler scrollbar), a first-visit loading screen and a quieter, less flat look, all in the site's own palette.

**Architecture:** Pure logic in `src/lib/*` with vitest tests; layered-SVG cat animated by CSS; thin client components wired to the existing sky (`useNow`, `skyAt`, `sunPosition`). An inline gate script marks `<html data-loader>` / `<html data-ruler>` before hydration. This is a **port** of a finished implementation in the sibling repo (read-only reference, see below) adapted to this repo's stack.

**Tech Stack:** Next 16 App Router, React 19, Tailwind v4, next-themes, zustand, vitest + jsdom + Testing Library, `playwright-core` (imported by file URL from the sibling repo's `node_modules`) for browser checks. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-18-cat-ruler-polish-design.md` (and `2026-11-18-loading-screen-design.md` for the loader's behaviour). Paths are relative to the repo root `duke-portfolio/` unless absolute.

**Palette rule:** the cat, ruler and loader use only this portfolio's tokens: no rainbow gradient, no spiral logo, no foreign brand colours.

## Global Constraints

- **Palette:** the cat and every new element use only this site's tokens (`--ink`, `--ink-soft`, `--ground`, `--rule`, `--accent`, `--sun`; the sky's own computed colours). **No rainbow/brand gradient across hues, no spiral or foreign logo anywhere.**
- No new dependencies. TypeScript uses **double quotes**; `npm run lint` must pass (inline type imports, no `console.log`, no `any`, `eqeqeq`); Next 16 differs from older versions (a generated `AGENTS.md` says so): consult `node_modules/next/dist/docs/` when unsure. Do not commit `AGENTS.md`/`CLAUDE.md` (generated by `next dev`).
- Timings: loader `minMs` 1400, `maxMs` 3500, reduced-motion `minMs` 600, gate `safetyMs` 3000, session key `"duke:loader-seen"`, path `/` only; ruler ticks every 2 %, labelled every 10 %, needle hidden below 3 %, rail ~40 px, `RULER_MIN_WIDTH` 900, `RAIL_TOP` 76, `RAIL_BOTTOM` 24, ruler gate safety release 5000 ms (unless `window.__rulerLive`); ruler cat grooms after 1200 ms idle, types within 150 ms of scrolling, naps from 98 %.
- Day/night is **sky phase**: night iff `skyAt(sunPosition(now, lat, lon)).phase === "night"`, else day; `?time=HH:MM` drives it.
- Only `transform`, `opacity` and `stroke-dashoffset` animate; reduced motion = static pose, no loops, no hop, quick fade for the loader; no per-frame React state; ONE passive scroll listener for the ruler (plus observers); pose state changes only when the POSE changes.
- Layers: header is `z-50`; the ruler sits below the header and below the loader and any open mobile menu, and never covers header controls (pick its exact z-index by measurement); the loader is `z-[100]`. `data-print="hide"` on decorative layers.
- All visible text through the dictionary (`Dictionary` keeps `en`/`mn` identical, `dictionary.test.ts`). Cat speech: 4 lines per language, short, smug, about clean code; the English has no Cyrillic; Mongolian is natural Cyrillic.
- Known nits from the reference implementation to avoid here: pass finite values into `rulerCatPose`; add a +1 px hysteresis to the ruler's `docHeight > viewport` test; don't re-render the ruler at night on day-only pose changes; keep decorative ruler text out of find-in-page (render labels with `data-*` + CSS `::after`, or `user-select: none` plus `aria-hidden`; prefer the former); keep the cat's hop within the rail lane.
- Dev server: run `npx next dev -p 3114` (port 3000 is another app, 3113 may be stale); one is already running on 3114. Playwright: `import { chromium } from "playwright-core"` and launch `chromium.launch({ channel: "chrome", ignoreDefaultArgs: ["--hide-scrollbars"] })` (Playwright hides scrollbars by default, which breaks ruler checks). Keep scripts and PNGs outside the repo (the session scratchpad or `%TEMP%`).
- Commit after each task; end every commit message with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (an implementer model may use its own name on that line). Work on a new branch from `redesign`. Commands from the repo root: `npm test -- <path>`, `npm run typecheck`, `npm run lint`.

## Review Focus

1. Day/night at the edges: `?time=` values around dawn and dusk give a defined state; an `undefined` phase or `null` now is day, never throws (Tasks 1, 3, 4).
2. Page shorter than the viewport, zero-height document, non-finite viewport: ruler progress is 0, no `NaN`, ruler not shown, native bar restored (Tasks 1, 5).
3. Document height changes after load: web fonts settle, images, and **switching language EN↔MN reflows every section**; needle and markers must stay correct (Task 5).
4. No JS / blocked or throwing `sessionStorage` / a font or `load` that never fires / unmount mid-load: page usable, scroll lock released, native scrollbar present, loader gone by `maxMs` (Tasks 1, 3, 5).
5. Scroll-locked and themed states: mobile menu open, light and dark theme, Mongolian language, reduced motion: ruler hidden or legible, labels translated, cat static (Tasks 3–6).
